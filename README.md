# 🎵 YouTube Music Downloader

Aplicação web em Node.js para descarregar músicas do YouTube em formato **MP3**, com conversão automática, metadados integrados e capas incorporadas no ficheiro de áudio.

---

## 🚀 Funcionalidades

- 🔍 **Análise de Links:** Exibe a capa, título e autor antes de iniciar o download.
- 🎧 **Áudio de Alta Qualidade:** Converte o fluxo de áudio para MP3 utilizando o FFmpeg.
- 🖼️ **Capa e Metadados:** Embute automaticamente a capa do vídeo e as informações do artista no ficheiro MP3.
- 👾 **Interface Interativa:** Animação personalizada do Pac-Man com barra de progresso em tempo real.
- 📁 **Organização Local:** Salva as músicas descarregadas diretamente na pasta `downloads/` do projeto.

---

## 🛠️ Tecnologias Utilizadas

- **Backend:** Node.js, Express, `yt-dlp-exec`, `ffmpeg-static`
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)

---

## 📋 Pré-requisitos

Garante que tens o [Node.js](https://nodejs.org/) instalado no teu computador.
